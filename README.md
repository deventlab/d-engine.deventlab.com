# d-engine.deventlab.com

Source of the [d-engine](https://github.com/deventlab/d-engine) product site: a static [Astro](https://astro.build) page, deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev     # http://localhost:4321
```

Pushing to `main` builds the site and deploys it through GitHub Actions.
